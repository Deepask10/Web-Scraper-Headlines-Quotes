# Web Scraper for Headlines & Quotes

A beginner-friendly Python web scraper that uses Requests and BeautifulSoup to extract quotes, authors, and tags from a website and save the collected data into JSON and text files.

## Features

- Sends HTTP requests using Requests
- Handles HTTP request errors
- Parses HTML using BeautifulSoup
- Extracts quotes
- Extracts authors
- Extracts tags
- Displays scraped data in the terminal
- Saves data into JSON format
- Saves data into a clean text file

## Technologies Used

- Python
- Requests
- BeautifulSoup4
- JSON
